*THIS VERSION IS ONLY FOR WINDOWS 11*
all files needed to rin the game are in \these_files to play

for 0.1.0 and 0.1.1
	download NewBeginnings version 0.1.0.exe, NewBeginnings version 0.1.0.pck, and inv_data.json
	open the .exe to start the game. this will create the directory: C:\Users\*username*\AppData\Roaming\Godot\app_userdata\NewBeginnings version 0.1.0
	copy the inv_data.json file into the directory C:\Users\*username*\AppData\Roaming\Godot\app_userdata\NewBeginnings version 0.1.0
	open the NewBeginnings version 0.1.0.exe to play
	when windows defender tried to stop you from opening click "more info" -> "run anyway"
